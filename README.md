# Machine Learning Assignment 2 — Classification Study

## 1. Problem statement

The objective is to implement and compare the classification algorithms specified
in the BITS Pilani Machine Learning Assignment 2 and then expose the trained
models through an interactive Streamlit application.

## 2. Dataset

I selected the Breast Cancer Wisconsin (Diagnostic) dataset.

- Number of observations: 569
- Number of predictor variables: 30
- Problem type: binary classification
- Target variable: `diagnosis`
- Classes: `malignant`, `benign`

The dataset satisfies the assignment's minimum requirements of 500 instances
and 12 features.

An 80:20 stratified split is used. `random_state=42` is fixed so the saved
models and the supplied holdout file can be reproduced.
